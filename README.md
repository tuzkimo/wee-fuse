# 一起拼豆（WeeFuse）

拼豆辅助 App：把图片转成可照着拼的拼豆图纸。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 目标平台

Android 平板优先。开发调试用浏览器与桌面端。

## 开发

```bash
npm ci
npm run dev      # http://localhost:1420
npm run test
npm run build
```

## 当前进度

第一阶段「图片转图纸」的**引擎**已完成：色彩空间与色差、MARD 221 色卡、面积平均重采样、
颜色量化、图纸构建与编辑撤销，全部为 `src/core/` 下的纯 TypeScript 模块，由单元测试覆盖。

应用层 **B1（骨架 / 工程文件契约 / 图纸库）** 已完成：浏览器里可以跑通
「选图 → 生成 → 自动落盘 → 图纸库 → 只读编辑器」。

应用层 **B2（选区页 / 尺寸·色卡·档位设置页）** 已完成：B1 的临时生成入口
（`GeneratePage.vue`，固定居中正方裁剪、一次点按即生成）已被真正的向导替换，该页与它的用例已删除。
`npm run dev` 后：

- `/` **图纸库**：封面是**图纸缩略图**（不是原图照片）、改名、二次确认删除、占用与配额；
  数据落在 IndexedDB（库名 `wee-fuse`，`projects` / `metas` / `sources` 三个 store）。
  存储层失败分**两种语义**（B2 §8）：**未注入**给「不允许本地保存」、**库打不开**显示原因，
  两种都**禁用「新建」**——用户不会白走一遍选图与生成。
- `/new` **选图页**：选一张图 → **一次解码同时**得到原图尺寸与长边 ≤1600 的预览位图，落进向导草稿后
  跳 `/new/setup`；失败（空文件 / 解码失败）给中文原因、不跳转、不留半截草稿。草稿里还有图时，
  另给一个「继续上次的选区」入口。
- `/new/setup` **选区 / 参数 / 结果**（一个页面三个阶段）：
  - **选区**：画布按 DPR 缩放；拖选框平移、拖四角手柄缩放；比例锁 **1:1 / 4:3 / 9:16**（也可自由）；
    **旋转 90°**（选框跟着图像内容一起转）；缩放档位 **适配 / 2× / 4×**（放大后能拖动平移，
    拖到边界就停住、不出现空白）；「重置选区」回到居中正方。手柄命中区 ≈48 CSS px，
    多指只有第一根手指生效。
  - **参数**：长边豆数（58 / 116 快捷值，也可手输 1–500）、用色档位 **简单 16 / 标准 32 / 精细不限**、
    尺寸摘要（成品颗数、厘米、需要几块板）与色卡声明；长边 > 300 时提示导出会分片但**不阻止**生成；
    选区每格分不到一个源像素时**阻止**生成，并说明该放大哪一条边。
  - **结果**：豆图预览 + 实际用色数 + 尺寸三行（尺寸走**产物自身**，不是参数面板的重算预测值）+
    **本次是新建还是覆盖**的明示（新建「已保存到图纸库」/ 覆盖「已更新这张图纸」）；
    「去编辑」跳编辑器；平板上还能页内回到选区。
  - **生成即落盘**：生成 → `adopt` + `save` → 进结果阶段；**改参数再生成是就地重跑，覆盖同一条记录**
    （id / 名称 / `createdAt` 不变，`updatedAt` 刷新），不会越跑越多条。
    **离开页面再回来也一样**：身份（`id` / 名称 / `createdAt`）存在 store 里、随草稿存活，
    所以「改参数 → 硬件返回键离开 → 从继续上次的选区回来 → 再生成」仍然覆盖同一条。
  - **保存失败不丢稿**：图纸留在内存、结果照常显示、给「重试保存」；**此时离开页面不清空草稿**
    （图纸不在库里，作废就等于图纸与草稿双丢），保存成功之后再离开才整份作废。
  - **平板左右分栏**（≥768px：左侧选区、右侧参数常驻）/ **手机单栏**（按阶段切换，底部「下一步 / 上一步」）；
    阶段与几何都活在 store 里，跨断点或横竖屏切换**不丢状态**。
  - 路由表本身有**用例**守着（`/new` 指的是选图页、`/new/setup` 指的是装配页，且 loader 解出的组件
    做**恒等**比较）。
应用层 **B3（编辑器）** 已完成：B1 的「只读编辑器」被真正的编辑器替换——缩放平移、画笔单颗与拖动连涂、
框选批量换色、吸管、撤销 / 重做、网格线与格内色号开关，调色板按**当前图纸的实时用色与颗数**列出；

去重跑 / 换 id）会被页面内的确认条拦下，**整页导航（改地址栏 / 刷新 / 关标签页）见下**。

  一次手势 = 一条撤销命令）、**框选批量换色**、**吸管**取色（含吸空格 = 橡皮）、**撤销 / 重做**
  （栈深 50，`Ctrl+Z` / `Ctrl+Shift+Z`）、网格线与格内色号开关；调色板按**当前图纸的实时用色与颗数**

  **编辑只改内存，显式「保存」才落盘**（裁决 1）：保存会**重算封面**并刷新 `updatedAt`，
  图纸库列表的封面与用色数随之更新；保存失败给琥珀条 + 「重试保存」，**内存里的改动不丢**。
  **有未保存改动时离开会被拦下**：**SPA 内的路由离开**（返回图纸库 / 去重跑 / 换 id）走页面内的

  刷新）页面会被卸载，页面内确认条不可能出现，**只**能靠 `beforeunload` 的浏览器原生提示——而**弹不弹由
  浏览器决定**：实测 Chrome 刷新有提示、**关闭标签页没有** ⇒ 后者**未保存的改动会静默丢失**。
  移动壳（Tauri）里没有标签页，**退出 / 切后台**的生命周期处理留给引入壳的那一轮（规格 §8.4）。

  ——**不额外拦截、不做第二次确认**；有未保存改动时仍走上面那条同一条确认条（裁决 2）。
  编辑器读参数一律走 `pattern`（图纸本体）与 `patternStats`，**不读 `meta` 的冗余字段**——后者是
  上一次保存时的值。
- `/lab/decode` **解码实验台**：同一张图对比两条解码路径的画质（回答规格 §12.1 的 R1）。

## 目录结构

- `src/core/` — 与框架无关的纯计算引擎（不得引用 Vue / Tauri / DOM 全局）
  - `color/`：Lab 转换与色差（ΔE76 / CIEDE2000）
  - `palette/`：色卡类型、内置 MARD 221 色卡与带校验的载入
  - `image/`：解码契约与类型、面积平均重采样、90° 旋转
  - `quantize/`：直方图、中位切割聚类、最近色查找
  - `pattern/`：图纸构建（`build.ts`）、**板与豆径换算（`board.ts`：5mm 豆、29×29 格/板、
    豆数→厘米 / 板数）**、用量统计、增量编辑、撤销栈、**编辑器视图数学（`view.ts`：默认缩放 /
