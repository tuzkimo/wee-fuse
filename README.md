# 一起拼豆（WeeFuse）

拼豆辅助 App：把图片转成可照着拼的拼豆图纸。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 目标平台

Android 平板优先。开发调试用浏览器与桌面端。

## 开发

```bash
npm ci
npm run dev      # http://localhost:1420
npm run test
npm run build
```

## 当前进度

第一阶段「图片转图纸」引擎开发中。功能二（AI 生图纸）与功能三（拼豆社区）尚未开始。
