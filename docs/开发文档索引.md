# 开发文档索引

面向开发者的地图：**东西都在哪**。

> 开发命令）——那份是**约定与规则**的真源，本文只是**索引**，不重复它的内容。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + TypeScript + Vite + Pinia + Tailwind CSS v4 |
| 客户端壳 | Tauri 2.0（Android 为主目标平台；桌面端仅用于开发调试） |
| 本地存储 | IndexedDB |
| 图像引擎 | 纯 TypeScript，零依赖、与框架无关（`src/core/`） |

## 环境要求

- **Node 22+**（本项目实测 Node 24.19.0）
- 要出 Android 包时另需：**Rust stable、Android SDK/NDK、JDK 17**

开发命令（`npm ci` / `dev` / `test` / `build` 与 `npx tauri android …`）见
[`AGENTS.md`](../AGENTS.md) 的「开发命令」与「平台壳」两节。
