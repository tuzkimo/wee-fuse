## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + TypeScript + Vite + Pinia + Tailwind CSS v4 |
| 客户端壳 | Tauri 2.0（Android 为主目标平台；桌面端仅用于开发调试） |
| 本地存储 | IndexedDB |
| 图像引擎 | 纯 TypeScript，零依赖、与框架无关（`src/core/`） |

## 环境要求

- **Node 22+**（本项目实测 Node 24.19.0）
- 要出 Android 包时另需：**Rust stable、Android SDK/NDK、JDK 17**

开发命令（`npm ci` / `dev` / `test` / `build` 与 `npx tauri android …`）见
[`AGENTS.md`](../AGENTS.md) 的「开发命令」与「平台壳」两节。

## `.superpowers/`（本机草稿，不入库）

`.superpowers/` 是 agent 会话的本机草稿区，**整个目录由根 `.gitignore` 忽略、从不进版本库**：
`brainstorm/` 放可视屏稿与会话密钥，`sdd/` 放 SDD 各轮的任务简报、实现报告、审查包与**控制者进度账本**。

**要知道的一件事（2026-10-12 查实，不是本次造成的）**：文档里提到 `.superpowers/sdd/<日期>-<主题>/` 的
地方共 **62 处、散在 15 个文件**（构建记录、计划、规格都有）。这些路径**从来只存在于当时那台机器上、
从未入库**，而且**本仓库的 `sdd/` 目录现在已经整个不在本机了**（me-blog / wee-count 两个项目的还在，
说明不是全盘清理）。所以：

- 读到「原始证据在 `sdd/...`」时，**别去找** —— 找不到是预期内的；那句话描述的是「当时的证据放在哪」，
  是真实的历史陈述，不是指向一个现在还能打开的文件。
- **持久证据的真源是各阶段的构建记录**（`docs/superpowers/notes/`），不是 sdd。上文「延后项唯一真源」
  那一列正是按这个口径填的。
- 需要长期留存的会话产物，按实例**另行**入库到 `docs/superpowers/notes/`——例如
  [2026-10-12-pixel-ui-mockups](superpowers/notes/2026-10-12-pixel-ui-mockups/)（那一轮的 4 张屏稿）。

历史上 `sdd/` 曾自带一份只写 `*` 的 `.gitignore` 自己忽略自己；2026-10-12 起那份已删，
统一由根 `.gitignore` 的 `.superpowers/` 一条覆盖。
