为什么这样摆：13 个按钮里真正高频的只有 4 个（画笔 / 橡皮 / 吸管 / 框选），它们排成长条放在拇指够得到的边；撤销·重做紧挨标题（画错了第一时间够得到）；保存靠右（绿色 ✓，右上角红点 = 有未保存的改动，代替「未保存」三个字）；剩下的 4 个是"看的方式"（网格线 / 色号 / 放大 / 缩小），收成小一号的一组放在工具条另一头。

我没把握的地方，标出来： 橡皮画成了方块+横线，像"垫子" 框选和"全屏"是同一个图标语言，可能混 吸管容易被当成画笔 ✓ 在没有文字的顶栏里够不够明显

手机和平板的差别只有一处：调色板从右栏变成底部一条可横滑的色豆。因为手机上横滑一排颜色，比缩成 3 列小方块好点得多。其余全部相同。
