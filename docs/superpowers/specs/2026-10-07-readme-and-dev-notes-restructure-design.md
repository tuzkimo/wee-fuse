**「功能特性」的逐条素材**（全部来自已交付事实，不许出现未交付项）：

- **图片 → 图纸**：相机 / 相册选图或拖入图片；矩形选区（拖移、四角缩放、比例锁
  `1:1 / 4:3 / 9:16`、旋转 90°、适配 / 2× / 4× 缩放档位、一键重置居中正方）；
  长边豆数 1–500（58 / 116 快捷值）；用色档位**简单 16 / 标准 32 / 精细不限**；
  内置 MARD 221 色卡；尺寸摘要（成品颗数、厘米、需要几块板）——**生成即落盘**。
- **图纸库**：封面是**图纸缩略图**而非原图；改名、二次确认删除、占用与配额。

> **落笔前必须回代码核对的三个数字/口径**（防抄错）：① MARD 色卡是否 221 色；
> ② 长边豆数范围是否仍为 1–500；③ 用色档位是否仍为 `16 | 32 | null`。
> 三处若已变，以代码为准（`AGENTS.md`「关键常量」是同步清单）。

- **编辑器**：缩放平移（双指捏合 / 双指拖动；桌面另有滚轮与 `Ctrl+滚轮` 以指针为锚）；
  画笔单颗与拖动连涂（8 连通补格，一次手势 = 一条撤销命令）；框选批量换色；吸管（吸空格 = 橡皮）；
  撤销 / 重做（栈深 50，`Ctrl+Z` / `Ctrl+Shift+Z`）；网格线与格内色号开关；调色板按
  **当前图纸实时用色与颗数**列出，可按 MARD 221 全色卡添加颜色；
  **编辑只改内存、显式「保存」才落盘**（保存会重算封面）；有未保存改动时在页面内离开会被确认条拦下。
- **导出三类 PNG**（逐张由手势保存）：**施工图**（网格 + 格内色号 + 每 5 格坐标刻度 +
  每 29 格拼豆板边界 + 信息条与页脚；超画布上限时按整块板自动分片）、
  **用量表**（色块 / 色号 / 名称 / 颗数 / 合计）、**分享图**（纯色块、空格透明）。
- **Android 壳（Tauri 2）**：相机 / 相册选图；**系统分享直接进 App**（只取第一张 + 提示告知）；
  **保存进系统相册**（MediaStore）；返回键三分支（有未保存改动不静默退出）。
- **本地优先**：数据存本机 IndexedDB，无后端、断网可用；**图像引擎是纯 TypeScript，与框架无关**。
- **色准**：颜色计算全在 CIE Lab 空间；逐格映射用 ΔE76，选色阶段用 CIEDE2000。
- **实物换算**：5mm 豆、29×29 格每板 ⇒ 成品厘米与需要几块拼豆板。

**「快速开始」要点**：

- 环境：Node 22+（本项目实测 Node 24.19.0）；出 APK 另需 Rust stable + Android SDK/NDK + JDK 17。
- 命令：`npm ci` / `npm run dev`（`:1420`）/ `npm run test` / `npm run build` /
  `npx tauri android dev` / `npx tauri android build --apk --debug`。
- **保留一行安装 hazard**（属部署信息、不是开发记录）：权威安装方式是 `npm ci`，
  `package-lock.json` 必须保留；干净环境裸跑 `npm install` 会撞上 npm 11.5.2 的 arborist bug。

**「获取安装包与发布」要点**：推 `v*` tag ⇒ Actions `release-android` 出 arm64
**已签名** release APK（`WeeFuse_<tag>_arm64.apk`）并自动挂 GitHub Release；
tag 必须与 `src-tauri/tauri.conf.json` 的版本号一致；本地出已签名包用
`npx tauri android build --apk`。**换钥匙、四个 secret、签名材料位置见发布指南**（不在 README）。
