## 怎么打开

用浏览器直接打开即可（每份都已补上 `<!DOCTYPE html>` 与当时服务端的框架样式，
`toggleSelect` 也用一个等价的最小实现补上了）。

**字体**：屏稿用的是缝合像素字体，`@font-face` 指向
`../../../src/assets/fonts/fusion-pixel-12px-proportional-zh_hans.woff2`。
**该文件由实现计划的 Task 5 落地**——在那之前打开这几张屏稿，中文会回退到系统字体
（像素感会差一截，但版式与配色是准的）。字体的来源 URL 与授权见规格 §6.2。

## 与最终规格的三处差异（如实记）

屏稿是**讨论中途**的产物，后来被人类伙伴的裁定改掉了三处，看屏稿时别被带偏：

1. `02-平板三栏.html` 的中栏写的是「会变成这样」并配了一句「改哪边中间立刻变」——
   那需要一条**实时预览管道**，是新功能。最终裁定是 **中栏显示「上一次的结果」**（规格 §7.3、§12 第 0 条）。
2. `03-编辑器双屏.html` 里的工具条画了 4 个工具——最终裁定删掉吸管与框选，
   **去背景并入填充**，只剩 3 个（规格 §8）。
3. `04-其余三屏.html` 里的施工图画了「3 / 12」翻页条和一个「色号」开关——
   **那两样在现有 `SheetViewer` 里根本不存在**（分页在打印面板）。规格 §7.6 已按真实的
   testid 重写，施工图**不做多页模型**。
