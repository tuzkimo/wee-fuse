C · 拼豆板

米色点阵底（就是拼豆板的孔），按钮做成豆粒的圆边，暖色系。最贴主题，小朋友一眼能认出「这是拼豆」；代价是和 MARD 色卡放一起时容易混成一片，得靠深色描边隔开。

想看的细节：主按钮的「描边+硬投影」在 A 和 C 里是主要识别手段，B 取消了；底部两个功能按钮在三套里用的是同一对图标（作品 / 新图）——顺便看看不配文字你能不能认出来。
